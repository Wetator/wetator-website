{{% cmd-register-cs-hint %}}

Double click with the mouse on the specified element.

Parameters

wpath
The WPath identifying the control to double click on {{% link-wpath-docu %}}.
It is possible to use the '*' and the '?' character as wildcards; '*' matches zero or many characters; '?' matches one single character.
It is also possible to define a {{% wpath-separator %}} separated list of words (with '*' and '?' if needed) to narrow down the context. The last part identifies the element to double click on; the preceding parts specify text that must appear before it on the page.

Examples

Double click an entry field

Double click on an entry field labeled 'Name'.
